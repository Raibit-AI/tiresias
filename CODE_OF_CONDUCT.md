# Code of conduct

We want working on Tiresias to be good for everyone involved.

- Be kind and assume good faith. Disagree about the work, never about the person.
- No harassment, insults, or unwelcome attention of any kind, in public or in private messages.
- Help newcomers. Everyone started somewhere.
- Keep security reports private (see SECURITY.md).

If someone breaks these rules, tell the maintainers privately (a private message to the Raibit-AI organization on GitHub). We read every report, keep it confidential, and may warn, suspend or remove anyone who does not stop.
